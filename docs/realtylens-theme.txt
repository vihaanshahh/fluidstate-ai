RealtyLens — Visual Theme
=========================
Source: landing/app/globals.css (single source of truth)
Inspiration: General Intelligence Company (generalintelligencecompany.com/writing) — editorial,
warm off-white, pastel-chip signature. Earlier landing page was "Cofounder-inspired" with cobalt
blue, but the live system has been re-themed to the GIC palette (with a few legacy tokens mapped
through for backwards compatibility).

------------------------------------------------------------------------------------------------
1. Mood / Aesthetic
------------------------------------------------------------------------------------------------
- Warm off-white foundation (not stark white, not gray) — feels like paper.
- Pure black for buttons and ink (CTA color is black, NOT blue).
- Seven pastel "chip" colors used as the editorial signature — backgrounds for tags, category
  icons, avatars, callout cards.
- Charcoal text on warm off-white. Subtle, low-contrast borders.
- Soft, slow animations (cubic-bezier(0.16, 1, 0.3, 1)). Reduced-motion fully respected.

------------------------------------------------------------------------------------------------
3. Typography
------------------------------------------------------------------------------------------------
- Font family: Inter (var(--font-inter)) → system-ui → -apple-system → sans-serif
- Body: 16px / 1.6 / weight 300 (light)
- Antialiased (-webkit-font-smoothing: antialiased)
- Brand wordmark / nav links: 13–15px, weight 400–600, letter-spacing -0.3px

------------------------------------------------------------------------------------------------
4. Motion / Animations
------------------------------------------------------------------------------------------------
Standard easing:    cubic-bezier(0.16, 1, 0.3, 1)
Default durations:  0.18s–0.7s

Named animations:
  fadeUp / fadeUpSm  — entrance translateY(20px → 0) + opacity
  fadeIn             — pure opacity
  scaleIn            — 0.96 → 1 + opacity
  routeEnter         — dashboard route transition (8px → 0)
  growBar            — progress bar fills from 0 → var(--target)
  barShimmer         — diagonal shimmer over running progress
  pulseHalo          — soft "Live" dot halo
  atmosDrift         — slow 14s drift on hero halo

Scroll-reveal utility classes:
  .scroll-fade-up / .scroll-fade-in / .scroll-fade-left / .scroll-fade-right / .scroll-scale-in

All motion is disabled under prefers-reduced-motion: reduce.

------------------------------------------------------------------------------------------------
5. Layout & Component Conventions
------------------------------------------------------------------------------------------------
- Styling system: CSS Modules (*.module.css) — NOT Tailwind. Each component owns its module file.
- Global tokens live ONLY in app/globals.css.
- Hero / nav max-width: 1240px, side padding 28px, nav height 64px.
- Nav background is transparent + backdrop-filter: blur(8px).
- Underline-on-hover for nav links (1px line, scaleX from right → left).
- Page-level animations go through lib/route-fade.tsx — don't roll new ones.

------------------------------------------------------------------------------------------------
6. Legacy Tokens (mapped through to GIC palette)
------------------------------------------------------------------------------------------------
Older code references --marble-*, --gold-*, --vine-*, --terracotta-*, --teal-*, --cool-*,
--success-*, --amber-*, --alert-*, --warm-*. These still exist but are aliased to the new
accent/chip/green tokens so the entire app stays in the GIC color world. New code should use the
canonical tokens above, not the legacy aliases.

------------------------------------------------------------------------------------------------
7. One-Sentence Theme Summary
------------------------------------------------------------------------------------------------
Warm, paper-like off-white surfaces with pure-black ink CTAs, charcoal text, seven pastel chip
accents, Inter type, and slow editorial fade/drift animations — a calm, magazine-style aesthetic
inspired by General Intelligence Company.
